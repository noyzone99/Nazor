# Nazor grammars

Editor setup, capabilities, and hot reload are documented in the [developer guide](../../../Docs/Guide/26-Editors-and-Hot-Reload.md).

This directory supplies TextMate grammars and language configuration for `.nazor` components and `.nss` stylesheets. The editor build script includes these assets in the Visual Studio and VS Code distributions. The C# grammar retains its [upstream license](csharp.tmLanguage.LICENSE.txt).

Highlighting recognizes syntax; the compiler and language server validate supported constructs. See the [NSS reference](../../../Docs/Guide/18-NSS-Syntax-and-Values.md) for accepted values and syntax.
